# interactive-calculator

Самостоятельный интерактивный проект: стоимость по составляющим.

[Открыть сайт](https://cherreshenka1.github.io/interactive-calculator/) · [Кейс](https://cherreshenka1.github.io/portfolio/projects/interactive-calculator/) · [Промпт и критерии доработки](https://github.com/cherreshenka1/portfolio/blob/main/prompts/interactive-calculator.md)

## Сценарий

Настроить параметры услуги, понять каждую часть суммы и сохранить расчёт.

Три режима расчёта показывают базовую стоимость, объём и доплаты. Сохранённые варианты можно сравнить; форма проверяет заполнение и сообщает локальный результат.

## Границы

Пример расчёта на условных тарифах. Форма не отправляет заявку исполнителю.

## Проверить вручную

1. Выбрать услугу.
2. Изменить параметры.
3. Проверить разбивку.
4. Сохранить расчёт.

Проверены основной сценарий и адаптивная вёрстка при ширине 390 и 1280 px. Это проверка прототипа, а не сертификация готовности к промышленной эксплуатации.

## Визуальная доработка

Перестроено 03.10.2026: самостоятельная композиция, навигация и пользовательский сценарий. Стили собраны в `src/project.css`; прежние общие оболочки отключены. Источники открытых данных: `public/data/open-data.json`; происхождение фотографий: `public/data/photo-sources.json`. Фотографии сохранены локально.

## Разработка

React 18, Vite 5. Node.js 20+.

```sh
npm ci
npm run dev
npm run build
```

`npm run deploy` собирает приложение и публикует `dist` в ветку `gh-pages` текущего репозитория.
